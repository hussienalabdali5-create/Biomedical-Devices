# Biomedical Devices Dashboard

A comprehensive **Biomedical Devices Standards & Risk Management** dashboard created by **Hussein Ali Hussein Omar Al-Abdali**.  
It documents **25 medical devices** across 6 categories with full standards (IEC 60601, ISO 13485, ISO 14971), maintenance tasks, risk assessments, and more.

## Features
- 📋 Detailed device specifications
- ⚠️ ISO 14971 risk management
- 🔧 Maintenance logs and printable reports
- 📷 Media folder links (Google Drive)
- 📱 PWA – installable on desktop and mobile

## How to Use
1. Open `index.html` in a modern browser.
2. Use the filters, search, and device cards.
3. Add/edit devices, import/export JSON.
4. Click "Install" in the browser address bar to use as an app.
